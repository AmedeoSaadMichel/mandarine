# Mandarine

Convert, edit, and collect files with a drag and a key.

## Install

Download the DMG, drag **Mandarine** to **Applications**, and open it. **FFmpeg is included.**

Look for the three-eyed mandarin in your menu bar. No Homebrew or extra installation is needed.

**First launch:** the app is not notarized by Apple. If macOS blocks it, follow the [first-launch instructions](docs/INSTALL.md#macos-blocks-the-app).

## Drag. Tap. Done.

Start dragging a file, tap a key, and drop onto the action you want.

| Key | Opens |
|---|---|
| **⇧ Shift** | Conversion wheel — choose an output format |
| **⌘ Command** | Tools wheel — crop, trim, compress, and more |
| **⌃ Control** | Actions wheel — open, reveal, duplicate, or copy |
| **⌥ Option** | Shelf — collect files for your next move |

With **Control**, start dragging **before** pressing the key. Shortcuts can be changed in Settings; the menu-bar menu also works without dragging.

## Keep files close

Persistent shelves offer grid, list, and compact stack views, Quick Look previews, and auto-hide at screen edges. Drag one file or a whole stack into another app. Original files stay in place.
